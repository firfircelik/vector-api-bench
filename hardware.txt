Run conditions: on AC power, kept awake with `caffeinate -dimsu`; no CPU pinning (macOS has no affinity API on Apple
silicon), so the API server, Postgres and the vegeta load generator share all 8 cores. Swap is the macOS compressor plus
swap files on the boot volume. The owner's normal apps were open during parts of the main run (see the article's
methods section and data/analysis/host_timeline_hourly.csv).
